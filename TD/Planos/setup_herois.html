Rodar o script automático Automático

No Unity, acesse o menu:

TD → Setup Sistemas (Planos 1-7)

O script vai executar automaticamente:

  • Criar pastas Assets/Data/Herois, Assets/Prefabs/Herois, Assets/Prefabs/UI/Herois
  • Criar HeroiDef_Pirata.asset com raridade Azul e id heroi_pirata
  • Criar HeroiDatabase.asset já com o Pirata cadastrado
  • Atualizar raridades das 3 relíquias existentes (Olho=Incomum, Bússola=Raro, Carvão=Comum)
  • Fazer ping no HeroiDatabase no Project panel
Verifique o Console para confirmar que tudo foi criado sem erros antes de continuar.
1
Aguardar compilação Automático

Ao abrir o Unity após o pull/save, ele compila todos os novos scripts. Aguarde a barra de progresso no canto inferior direito desaparecer e verifique que não há erros em vermelho no Console.

Se houver erros de compilação, resolva antes de continuar. Erros impedem qualquer operação de editor.
2
Criar o Prefab do Herói Pirata Manual

Na Hierarchy, clique direito → Create Empty → nomeie HeroiPirata.

Adicione os componentes na ordem:

Componente Configuração
HeroiPirataControllerVida Máxima: 150 · Dano Base: 20 · Facção: Jogador
MovimentoUnidadeVelocidade padrão
SistemaIAUnidadePadrão
AnimacaoSpritePorVelocidade2DArrastar sprites de Assets/Sprites/Herois/Pirate/
Rigidbody 2DBody Type: Dynamic · Gravity Scale: 0 · Freeze Rotation Z: ✓
Capsule Collider 2DAjustar tamanho ao sprite

Configurar Animação

No componente AnimacaoSpritePorVelocidade2D:

  • Arraste os sprites de corrida horizontal em Sprites Andar
  • Defina o sprite parado em Sprite Parado
  • Ajuste Tempo Por Frame (~0.1s)

Salvar como prefab

Arraste o GameObject da Hierarchy para Assets/Prefabs/Herois/.

Depois abra Assets/Data/Herois/HeroiDef_Pirata no Inspector e arraste o prefab no campo Prefab.

3
Configurar HeroisManager nas cenas de Lobby Manual

Repita para cada cena de Lobby (LobbyGoblin, LobbyElfo, LobbyAnoes, LobbyHumano):

  1. Abra a cena no Unity
  2. Encontre (ou crie) o GameObject HeroisManager na Hierarchy
  3. No Inspector, arraste Assets/Data/Herois/HeroiDatabase no campo Heroi Database
  4. Salve a cena (Ctrl+S)
O HeroisManager já usa DontDestroyOnLoad, então basta configurar em uma cena se ele for persistente.
4
Adicionar SistemaTendasManager Manual

Em cada cena de Lobby (ou no GameManager persistente):

  1. Hierarchy → Create Empty → nomeie SistemaTendasManager
  2. Add Component → Sistema Tendas Manager
  3. Salve a cena
Assim como o HeroisManager, usa DontDestroyOnLoad — coloque só em uma cena se for persistente.
5
Montar a UI de Heróis no Lobby Manual

5.1 — Criar o prefab de item de herói

  1. Hierarchy → Create Empty → nomeie HeroiItem
  2. Add Component → Heroi Item Controller
  3. Adicione filhos (UI → Text):
    • TextoNome — arraste no campo Texto Nome
    • TextoFases — arraste no campo Texto Fases
  4. Adicione filho (UI → Image) → nomeie IconeAlerta — desative-o no Inspector — arraste no campo Icone Alerta
  5. Arraste o GameObject para Assets/Prefabs/UI/Herois/ para criar o prefab HeroiItem

5.2 — Montar o painel no Canvas do Lobby

  1. No Canvas existente, crie um Button → texto: Heróis
  2. Crie um Panel filho do Canvas → nomeie PainelHerois → desative no Inspector
  3. Dentro do PainelHerois: UI → Scroll View
  4. No ScrollView → Content: Add Component → Vertical Layout Group
  5. Crie um GameObject vazio no Canvas → Add Component → Painel Herois Controller
  6. Configure no Inspector:
    CampoO que arrastar
    PainelO GameObject PainelHerois
    Container ItensO Content do Scroll View
    Prefab Item HeroiO prefab HeroiItem
  7. No Button Heróis → OnClick() → arraste o objeto com PainelHeroisController → selecione AbrirPainel()
