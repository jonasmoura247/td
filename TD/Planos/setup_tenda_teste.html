Setup de Tendas de Teste no Unity

Guia prático para deixar o fluxo funcional com quadrados temporários, clique no mapa, painel de tenda e escolhas persistidas.

Tendas Heróis Relíquias Teste sem sprite final

O que já foi preparado no código

  • As tendas agora podem ser geradas e persistidas por seed no EstadoEventosRun.
  • As ofertas de relíquias e heróis ficam fixas depois de geradas.
  • Foi criado um bootstrap para spawnar um marcador de tenda ao lado da próxima fase disponível.
  • O painel de tenda aceita botões de teste e já processa contratar herói, renovar e pegar relíquia.
  • Os contratos dos heróis agora avançam ao vencer a fase.

Passo 1: configurar as bandeiras de fase

  1. Abra uma cena de mapa mundo, por exemplo Assets/Scenes/Mapas/Mapamundo_1/Mapa_Natural.unity.
  2. Selecione cada objeto com BandeiraFaseController.
  3. No Inspector, preencha os novos campos:
    • Mundo Id: número do mapa mundo. Exemplo: Natural = 1, Gelo = 2, Magma = 3.
    • Indice Fase: ordem da fase dentro daquele mapa.
  4. Faça isso pelo menos na fase disponível atual, porque o bootstrap usa a próxima fase disponível para decidir se mostra a tenda.
Se uma bandeira estiver sem Mundo Id e Indice Fase coerentes, a tenda pode aparecer associada à fase errada.

Passo 2: garantir managers persistentes

  1. Abra cada lobby principal que o jogador usa para entrar no mapa:
    • LobbyGoblin
    • LobbyElfo
    • LobbyAnoes
    • LobbyHumano
  2. Garanta um objeto HeroisManager com o campo Heroi Database apontando para Assets/Data/Herois/HeroiDatabase.asset.
  3. Garanta um objeto SistemaTendasManager na cena.
  4. Salve a cena.

Esses dois usam DontDestroyOnLoad, então basta entrar normalmente pelo lobby.

Passo 3: criar o marcador de tenda como quadrado de teste

  1. Na Hierarchy, use GameObject → 2D Object → Sprites → Square.
  2. Renomeie para TendaMarcadorTeste.
  3. Adicione o componente TendaMarcadorMapa.
  4. Confirme que ele tem um Collider2D. Se não tiver, adicione um BoxCollider2D.
  5. No SpriteRenderer, mude a cor para algo bem visível, por exemplo laranja.
  6. Ajuste a escala para algo como (0.5, 0.5, 1).
  7. Arraste esse objeto para uma pasta de prefabs, por exemplo Assets/Prefabs/Tendas/.
Esse quadrado será o marcador clicável da tenda. Não precisa de sprite final agora.

Passo 4: criar um botão de opção simples para o painel

  1. No Canvas, crie um UI → Button - TextMeshPro.
  2. Renomeie para TendaOpcaoBotao.
  3. No objeto raiz do botão, adicione o script TendaOpcaoBotaoController.
  4. No Inspector do script:
    • Botao = o componente Button do próprio objeto.
    • Texto Tmp = o texto filho do botão.
  5. Arraste esse botão para virar prefab, por exemplo em Assets/Prefabs/UI/Tenda/.

Passo 5: montar o painel da tenda

  1. No Canvas do mapa mundo, crie um painel raiz chamado PainelTenda.
  2. Deixe esse painel desativado no Inspector.
  3. Dentro dele, crie:
    • Um texto Titulo
    • Um texto Descricao
    • Um container SecaoReliquias
    • Um child dentro dele chamado ContentReliquias
    • Um container SecaoHerois
    • Um child dentro dele chamado ContentHerois
    • Um botão Fechar
  4. Nos dois containers de content, adicione Vertical Layout Group.
  5. Crie um objeto vazio chamado PainelTendaController e adicione o script PainelTendaController.
  6. Preencha no Inspector:
    • Painel = objeto PainelTenda
    • Texto Titulo = texto do título
    • Texto Descricao = texto da descrição
    • Secao Reliquias = objeto da seção
    • Container Reliquias = ContentReliquias
    • Prefab Botao Opcao = prefab TendaOpcaoBotao
    • Secao Herois = objeto da seção de heróis
    • Container Herois = ContentHerois
    • Reliquia Database = seu asset de banco de relíquias
    • Heroi Database = Assets/Data/Herois/HeroiDatabase.asset
  7. No botão Fechar, ligue o OnClick() para PainelTendaController → FecharTenda().

Passo 6: adicionar o bootstrap no mapa mundo

  1. Na cena do mapa mundo, crie um objeto vazio chamado TendaMapaBootstrap.
  2. Adicione o componente TendaMapaBootstrap.
  3. Preencha no Inspector:
    • Painel Tenda = objeto com o script PainelTendaController
    • Reliquia Database = seu banco de relíquias
    • Heroi Database = HeroiDatabase.asset
    • Prefab Marcador Tenda = prefab TendaMarcadorTeste
    • Offset Marcador = algo como (1.5, 0.75, 0)
Quando a cena do mapa abrir, esse bootstrap vai procurar a próxima fase disponível e, se a seed disser que existe tenda, ele instancia o quadrado ao lado da bandeira.

Passo 7: validar o herói Pirata

  1. Abra Assets/Data/Herois/HeroiDef_Pirata.asset.
  2. Confira se o campo Prefab está apontando para Assets/Prefabs/Herois/HeroiPirata.prefab.
  3. Se estiver vazio no Inspector, arraste manualmente o prefab para o campo.

Eu já deixei a referência preparada no asset, mas vale validar no Unity porque prefab/fileID às vezes muda com reimport.

Como testar

  1. Entre no jogo pelo fluxo normal de slot e lobby.
  2. Abra um mapa mundo.
  3. Veja se um quadrado de tenda apareceu perto da próxima fase disponível.
  4. Clique no quadrado.
  5. Escolha uma relíquia, um herói ou ambos, dependendo do tipo de tenda.
  6. Feche o painel.
  7. Reabra o mapa ou reinicie o jogo e confirme que as opções continuam iguais para aquela fase.

Checklist final

  • [OK] Cada BandeiraFaseController relevante tem Mundo Id e Indice Fase.
  • [OK] Existe SistemaTendasManager no fluxo de entrada.
  • [OK] Existe HeroisManager com HeroiDatabase.
  • [OK] O mapa mundo tem TendaMapaBootstrap.
  • [OK] O prefab do marcador da tenda é um quadrado clicável.
  • [OK] O painel tem botão de fechar e prefab de opção configurado.
  • [Atenção] Rode o Test Runner do Unity para validar EditMode após o refresh dos scripts.
