Plano 9 — Sistema de Estatisticas do Jogador

Torre Defense · Goblins, Humanos, Elfos e Anoes · Implementacao completa do zero

1. Visao Geral

Criar um sistema completo de rastreamento de estatisticas integrado ao fluxo de save existente (JSON via SaveSlotManager) e exposto por um painel de UI acessivel atraves do BotaoEstatisticas ja presente em cada lobby de raca. Um menu no Editor (TD → Estatisticas) recriar a UI nos 4 lobbies com um clique.

O botao BotaoEstatisticas ja existe nas cenas de lobby. O editor tool so precisa encontra-lo, criar o painel e ligar os eventos.

2. Arquitetura

O projeto separa logica pura de wrappers Unity. O sistema de estatisticas segue o mesmo padrao:

DadosEstatisticas new

  • Modelo [Serializable]
  • EstatisticasGlobais globais
  • List<EstatisticasPorRaca>
  • Propriedades derivadas (WinRate, KPM...)
  • Metodo Normalizar()

EstatisticasLogica new

  • Classe pura sem MonoBehaviour
  • Testavel isoladamente
  • Recebe DadosEstatisticas no construtor
  • Todos os metodos RegistrarXxx()

EstatisticasManager new

  • Singleton MonoBehaviour
  • DontDestroyOnLoad
  • Assina eventos de kills, ouro, waves
  • Salva ao finalizar partida

LobbyEstatisticasController new

  • Segue padrao LobbyBestiarioController
  • Conecta BotaoEstatisticas ao painel
  • Garante EstatisticasManager no Awake

PainelEstatisticas new

  • 4 abas: Geral / Combate / Economia / Racas
  • ScrollRect por aba
  • Campos TMP sem emoji, sem acentos
  • Metodo publico AoAbrirPainel()

SetupEstatisticasLobbyMenu new

  • Menu: TD → Estatisticas → ...
  • Cena atual OU todas as 4 cenas
  • Limpa objetos antigos por nome E por componente
  • Sem emoji · Sem acentos nos textos TMP
  • Guard: bloqueia em Play Mode

6. Fluxo de Dados em Tempo de Execucao

1
Lobby carrega → EstatisticasManager.Awake → GarantirExistencia(). Inicializa EstatisticasLogica com dados do PerfilJogadorAtivo.
2
Cena Mapa_ carrega → EstatisticasManager detecta pelo nome da cena, registra _inicioPartida = DateTime.Now, assina eventos de ouro, waves, torres.
3
Inimigo morre → UnidadeController.Morrer() dispara OnUnidadeMorreu → EstatisticasManager filtra faccao == Inimigo → logica.RegistrarKill(nomePrefab, racaInimiga, racaAtual).
4
Ouro coletado → OuroManager.OnOuroAdicionado(delta) → logica.RegistrarOuroAdicionado(delta, racaAtual).
5
Ouro gasto → OuroManager.OnOuroGasto(delta) → logica.RegistrarOuroGasto(delta). Tambem atualiza AtualizarMaiorOuro(saldoAtual).
6
Wave completa → WaveManager.OnWaveCompletada(numeroWave) → logica.RegistrarWaveCompletada(num).
7
Torre construida/destruida → TorresManager.OnTorreConstruida/Destruida → logica.RegistrarTorreConstruida/Destruida().
8
Partida finalizada → RunExpPartida.OnPartidaFinalizada(vitoria, duracao, xp) → EstatisticasManager calcula duracao real, chama logica.FinalizarPartida() e salva via SaveSlotManager.
9
Lobby abre painel → BotaoEstatisticas.onClick → LobbyEstatisticasController.AbrirPainel() → PainelEstatisticas.AoAbrirPainel() → le dados atuais e popula todos os campos TMP.

7. Editor Tool — Menu TD → Estatisticas

Dois itens de menu:

TD / Estatisticas / Configurar UI no lobby (cena atual) TD / Estatisticas / Configurar UI em TODOS os lobbies (4 cenas)

Logica do SetupEstatisticasLobbyMenu.ConfigurarInterno()

1
Guard Play Mode: se EditorApplication.isPlaying → dialog de erro e return.
2
Encontra BotaoEstatisticas na cena (inclui inativos, busca recursiva).
3
Cleanup robusto: RemoverSeExistir por nome ("PainelEstatisticasRaiz", "ControleEstatisticas") E GetComponentsInChildren<PainelEstatisticas> + <LobbyEstatisticasController> para pegar objetos de versoes anteriores.
4
Cria hierarquia UI: PainelEstatisticasRaiz (tela cheia) → BarraTitulo + Conteudo → AbasBar + ContainerPaineis → 4x PainelScroll com Content.
5
Popula linhas via CriarLinha() e CriarSecaoTitulo(). Todos textos: ASCII puro, sem emoji, sem acentos.
6
Wiring serializado: SetTMP() para cada campo de PainelEstatisticas. Arrays de abas e paineis.
7
Cria ControleEstatisticas com LobbyEstatisticasController. Liga BotaoEstatisticas.onClick → AbrirPainel(). Liga BotaoFechar.onClick → FecharPainel().
8
SetDirty + salvar cena (se modo TODOS). Raiz do painel inicia inativo.
IMPORTANTE: CriarGO() ja chama AddComponent<RectTransform>(). Nao chamar AddComponent<RectTransform>() novamente apos CriarGO() — isso gera erro "already added". Usar apenas GetComponent<RectTransform>().

8. Persistencia

  • DadosEstatisticas e campo de DadosSlotSave → persistido no mesmo JSON do save slot
  • Atualizado in-place via referencia — sem copia, consistencia garantida
  • Salvo apenas ao finalizar partida (nao a cada kill/frame)
  • Saves antigos sem o campo → Normalizar() cria o objeto automaticamente
  • Valores negativos em saves corrompidos → Normalizar() clampeia para 0

9. Deteccao de Raca Inimiga

11. Edge Cases Tratados

  • Nenhuma partida jogada → campos mostram "—" na UI (nunca divide por zero)
  • tempoMenorPartida = -1 ao criar perfil novo → UI exibe "—"
  • Raca inimiga nao detectavel → kill conta no total, nao quebra
  • App fechado no meio da partida → match NAO e contado (so salva ao finalizar)
  • Saves antigos sem campo estatisticas → criado automaticamente no Normalizar()
  • Valores negativos em saves corrompidos → Normalizar() clampeia para 0
  • Editor tool em Play Mode → dialog de erro + return (sem crash)
  • AddComponent redundante de RectTransform → NUNCA chamar apos CriarGO()
